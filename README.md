# Horror Tattoo Web

Landing page oficial del emprendimiento **Horror Tattoo**.  
Página pública que lleva a los clientes al Instagram del tatuador para ver proyectos y agendar citas.

---

## Características

- Galería de proyectos con carga progresiva
- Lightbox para ver tatuajes en detalle
- Eslogan dinámico con el mes actual (zona horaria Chile)
- Diseño responsivo
- Enlace directo a Instagram
